> [!NOTE]
> ### 📌 Project Overview
> This project represents the **Homepage** assignment from **The Odin Project's Intermediate HTML & CSS** course. The primary objective is to build a fully responsive, modern single-page portfolio layout from scratch based on a provided design mockup.

---

## 🎯 About

The goal of this project was to master complex layout arrangements and responsive transitions between mobile, tablet, and desktop views.

* 📱 **Mobile-First Foundation** - Clean single-column view designed specifically for smaller screens.
* 📐 **CSS Grid & Flexbox Masterclass** - Dynamic project card layouts utilizing CSS Grid and flexible header/footer structures.
* 💻 **Adaptive Layouts** - Multi-breakpoint media queries targeting tablets (`min-width: 600px`) and laptops (`min-width: 1024px`).
* 🎨 **Layering & Shadows** - Creative visual depth using overlapping containers, custom gradients, and CSS drop-shadows.
